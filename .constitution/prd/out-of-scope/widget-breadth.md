# Out of Scope: Generic Widget Breadth as Substitute for Productization

Broad new widget breadth as a substitute for productization, release trust, and framework-level interaction foundations is explicitly out of scope.

## Rationale

The productization and framework ergonomics work (Epics U and V) is the critical path to credible public release. Adding widget breadth without first establishing expert-level SDK DX would produce a framework that looks broad but feels immature to early adopters.

## Anti-Pattern Avoided

Do not use "missing widget" reports as justification for expanding native widget surface before SDK productization is complete. Composite patterns over existing primitives are the correct response to missing widget requests during the productization wave.
