# Out of Scope: Host Runtime Expansion Beyond Bun

Host runtime expansion beyond the current Bun-first public posture is deferred for the immediate roadmap wave.

## Rationale

The Bun-first posture is a deliberate choice that reflects the FFI model, the performance contract, and the target developer audience. Node.js portability adds compatibility surface area and testing matrix expansion that would dilute focus from the primary pre-GA delivery goals.

## Future Consideration

Node.js or Deno support may be revisited after the first public npm publish and feedback loop, based on community demand.
